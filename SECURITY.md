# Security policy

RMBG is a static, client-side application. The project does not operate a
backend that receives or processes image files. The app does load its inference
runtime and model weights from third-party CDNs on first use; see the README and
in-app FAQ for details.

## Reporting a vulnerability

Please report suspected vulnerabilities in the app, repository, or dependency
chain privately to **velmet44@gmail.com**. Include the affected URL or commit and
steps to reproduce. Please do not open a public issue until the maintainer has
had a chance to assess the report, and do not send private photos, credentials,
or other sensitive data.

There is no bug bounty or guaranteed response time. This project has no stable
release channel; reports should identify the affected commit or deployed URL.
