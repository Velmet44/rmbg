# Contributing

## Quick start

1. Fork and clone: `git clone https://github.com/Velmet44/rmbg.git`
2. Create a branch: `git checkout -b <scope>/<short-name>`
3. Make a focused change, keep `AGENTS.md` updated if you add toolchain quirks.
4. Open a PR with what changed and how you verified it.

## Expectations

- Keep PRs small and scoped.
- Do not commit secrets, credentials, or local env files.
- Add tests for behavior changes once a test runner exists.
